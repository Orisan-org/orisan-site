What we are building

An evidence layer.
And a brake.

One local binary in the path of an agent's actions. Every call reduced to the same shape, attributed to an actor, written to a record a third party can check. The binary that watches is the one that can stop an action before it lands.

None of that ships yet. What exists today is below, with dates. Every factual claim on this site is listed in a public file with the source that verifies it.

Build log

What changed, and when.

Every entry is something that actually happened, including the mistakes. If you want to know whether this is real, read this and not the rest of the page.

12 Aug 2026

Found a colour we never authorised in our own stylesheet.

Our build asserts that default framework colours cannot compile. A stricter check found one shipping anyway, from a base layer nobody had inspected. The old check could not have caught it.

11 Aug 2026

The type scale was not monotonic below 612px.

One step had been tuned in isolation and crossed its neighbour, so a smaller heading rendered larger on a phone. Fixed, and gated so it cannot recur.

24 Jul 2026

mcpscan 0.1.1.

Pinned the protocol SDK after a new major release silently disabled remote transport on fresh installs. Added a weekly canary that installs the built wheel into a clean environment, because testing the repository instead of the artifact is what let it through.

10 Jul 2026

mcpscan 0.1.0 published.
